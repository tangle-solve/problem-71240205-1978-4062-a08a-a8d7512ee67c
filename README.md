### ALGO-000052: Optimal-seed generators for general branching programs
- **Subfield:** Pseudorandomness, derandomization, and Boolean analysis
- **Open:** Construct an explicit generator with \(O(\log n)\) seed length fooling polynomial-length, polynomial-width read-once branching programs to inverse-polynomial error.
- **Status:** A longstanding target beyond currently available general seed-length bounds. Merely proving BPL = L would not automatically provide this particular black-box generator.
- **Type:** theory
- **Why:** Supplies reusable, randomness-efficient simulation rather than problem-specific derandomization.
- **Key works:** Nisan (1992); Tal (2020), *Derandomizing Space-Bounded Computation* workshop materials; Shalunov (2024).
- **Related:** Streaming systems—small-state reproducible randomization.
